| 2 | Gmail in Chrome | Dictate a two-sentence reply | Complete, lightly formal sentences |
| 3 | Jira in Chrome | Dictate a ticket comment | Clear, neutral text |

| 5 | Terminal | Dictate "list the files" | Exact words, no polish |
